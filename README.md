# 文件名大写转换

一个纯本地运行的网页小工具：选择一个文件夹后，它会把该文件夹内所有文件名中的小写英文字母转换为大写，其他字符保持不变。

例如：`report-final_v2.docx` 会变为 `REPORT-FINAL_V2.DOCX`。

## 使用说明

1. 使用最新版 Chrome 或 Edge 打开网页。
2. 点击“选择文件夹”，选择需要处理的文件夹。
3. 核对预览列表后，点击“确认改名”。

文件不会上传到任何服务器；工具只处理所选文件夹的第一层文件，不会改动子文件夹和文件内容。

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```
